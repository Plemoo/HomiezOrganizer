# App icon assets

Generated from `app-icon-source.png` with `scripts/generate-brand-assets.py`.

- `app-icon.png`: 1024x1024 opaque icon used by iOS and legacy Android.
- `android-adaptive-foreground.png`: transparent Android adaptive foreground.
- `android-monochrome.png`: transparent Android 13+ themed icon.
- `notification-icon.png`: 96x96 all-white Android notification icon.
- `splash-icon.png`: transparent launch-screen mark.
- `store/apple-app-store-icon-1024.png`: App Store upload/reference asset.
- `store/google-play-icon-512.png`: Google Play listing icon.

The Android adaptive background and neutral notification accent color are
`#0A0A0A` and `#B8B8B8` respectively.
